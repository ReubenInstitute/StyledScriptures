# StyledScriptures

Text, Psalms, and Parashot classes that present Reuben Institute's own
typesetting of the Psalms (as poetry) and Parashot (as narrative prose),
with print-quality typography (curly single/double quotes, proper
punctuation) — the same text across print, web app, and social media
video.
